# مواعيدي

تطبيق لتنظيم مواعيد العائلة ودروس الأبناء: لكل فرد لون ونغمة تنبيه، ووضع للطفل بقفل برمز ولي الأمر، وتنبيهات بانتهاء الدرس أو تأجيله.

## الحصول على ملف APK (دون تثبيت أي برامج)

1. أنشئ مستودعًا جديدًا على github.com.
2. ارفع كل محتويات هذا المجلد إلى المستودع. إذا رفعت من المتصفح فاسحب المجلد كله، وتأكد أن المجلد المخفي `.github` ظهر في المستودع.
3. افتح تبويب **Actions** ثم اختر **Build APK**.
4. اضغط **Run workflow** (يبدأ البناء تلقائيًا أيضًا عند كل رفع جديد). ينتهي في نحو 5 إلى 8 دقائق.
5. افتح عملية البناء الناجحة، ومن أسفل الصفحة نزّل الملف **mawaidi-apk**.
6. فك الضغط لتجد `app-debug.apk`، وانقله إلى هاتف أندرويد وثبّته. قد يطلب الهاتف السماح بالتثبيت من مصدر غير معروف.

## الملفات

- `www/index.html`: التطبيق نفسه (صفحة واحدة).
- `assets/`: الأيقونة (`icon.svg` والمصادر بصيغة PNG).
- `capacitor.config.json`: اسم التطبيق ومعرّفه `com.mawaidi.app`.
- `.github/workflows/build-apk.yml`: خطوات بناء الـ APK على GitHub.

## البناء على جهازك (اختياري)

يلزم Node.js 20 وJava 17 وAndroid SDK:

```
npm install
npx cap add android
npm run icons
npm run sync
npm run apk
```

الناتج: `android/app/build/outputs/apk/debug/app-debug.apk`

## ملاحظات

- هذه نسخة تجريبية (debug) صالحة للتثبيت المباشر. للنشر في Google Play يلزم بناء نسخة release موقّعة بمفتاح خاص بك.
- البيانات تُحفظ على الهاتف نفسه. التنبيهات الصوتية تعمل والتطبيق مفتوح، ولتنبيهات تصل والتطبيق مغلق يلزم إضافة إضافة الإشعارات المحلية (`@capacitor/local-notifications`).
- حسابات منفصلة لكل طفل على هاتفه تحتاج خادمًا، وهي خطوة لاحقة.
